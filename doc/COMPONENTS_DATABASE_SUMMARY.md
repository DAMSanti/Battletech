## 🎮 Características Especiales Implementadas

### Propiedades de Armas

- `cluster`: Armas LB-X con dispersión
- `ultra`: Puede disparar doble (requiere tirada)
- `rotary`: Ráfaga rápida variable
- `streak`: Solo consume munición si impacta
- `multi_missile`: Puede disparar LRM o SRM
- `one_shot`: Lanzacohetes desechables
- `heat_damage`: Añade calor al objetivo
- `explosive`: Munición explosiva peligrosa
- `to_hit_modifier`: Bonus/penalización de precisión

### Propiedades de Equipamiento

- `weight_savings_percent`: Ahorro de peso
- `weight_penalty_percent`: Penalización de peso
- `armor_bonus_percent`: Bonus de protección
- `damage_reduction`: Reducción de daño
- `ecm_range`: Rango de interferencia
- `sensor_range`: Rango de detección
- `heat_dissipation`: Calor disipado por turno
- `speed_bonus_percent`: Bonus de velocidad
- `side_torso_critical`: Vulnerable en torsos

## 🔧 Uso en Código

### Obtener un Arma
```gdscript
var weapon = ComponentDatabase.get_weapon("er_large_laser")
print(weapon.name)  # "ER Large Laser"
print(weapon.damage)  # 8
print(weapon.heat)  # 12
```

### Obtener Munición
```gdscript
var ammo = ComponentDatabase.get_ammo("gauss_ammo")
print(ammo.shots_per_ton)  # 8
```

### Obtener Equipamiento
```gdscript
var ecm = ComponentDatabase.get_equipment("ecm_suite")
print(ecm.ecm_range)  # 6 hexes
```

### Listar Armas por Categoría
```gdscript
var energy_weapons = ComponentDatabase.get_weapons_by_category(
    ComponentDatabase.WeaponCategory.ENERGY
)
for weapon in energy_weapons:
    print(weapon.name)
```

## 🚀 Características Notables

### Armas Ultra
Las armas Ultra pueden disparar dos veces en un turno, pero con riesgo de atasco.

### Armas LB-X
Pueden disparar munición estándar (daño concentrado) o cluster (dispersión para mejor to-hit).

### Streak
Solo consumen munición si el disparo impacta (requiere lock-on).

### MASC + TSM
Combinados dan bonus masivos de velocidad y fuerza cuando el mech está caliente.

### Stealth Armor
Proporciona ECM integrado pero genera +10 calor por turno cuando está activo.

### XL Engine
Ahorra mucho peso pero si pierdes un torso lateral, el mech es destruido.

---

## 📝 Notas de Balance

- **Armas Clan** generalmente son más eficientes (menos peso, mismo daño, más alcance)
- **Equipamiento avanzado** tiene trade-offs (ahorro de peso vs slots o vulnerabilidad)
- **Ultra/Rotary** armas tienen riesgo de atasco con uso intensivo
- **CASE II** es superior a CASE pero pesa el doble
- **Ferro-Fibrous Clan** es objetivamente mejor que IS (más protección, menos slots)
